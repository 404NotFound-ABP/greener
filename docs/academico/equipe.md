## Limites da evidência no corte da Sprint 1 (19/10)

- Os commits da conta do projeto não permitem identificar qual integrante realizou cada alteração.
- Não existem pull requests, reviews ou registros de pareamento.
- Commits não referenciam os números das issues.
- Estar atribuído a uma issue comprova responsabilidade planejada, não conclusão.
- Lockfiles concentram grande parte das linhas alteradas; volume de linhas não é usado como medida de contribuição.

Os nomes completos e as contribuições realizadas fora do GitHub devem ser confirmados pela equipe antes da entrega final.
